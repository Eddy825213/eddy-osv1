# Eddy's Personal Profile Website

🎉 **Welcome to my personal profile website!** 🎉  
A sleek, anime-style OS-inspired personal profile with cool features like a gamified experience, character cards, visual novel chat, and more!

## 🚀 Features

- **Anime-Style OS Theme**  
  A unique "anime-style OS" interface with cinematic effects, character cards, and a terminal-style admin panel.

- **Gamification**  
  Earn XP, badges, and enjoy a customized journey with a timeline.

- **Dark/Light Mode**  
  Toggle between dark and light mode with smooth animations for a better browsing experience.

- **Password-Protected Visual Novel Screen**  
  Unlock the "visual novel" screen with a secret password!

- **Interactive Timeline**  
  A dynamic journey timeline that updates in real time with descriptions based on the current time.

- **Music**  
  Lo-fi and piano music plays in the background with an option to turn it on/off and save the state.

- **Profile Features**  
  Easily update your bio, profile picture, and showcase your skills and projects.

---

## 🔧 Technologies Used

- **HTML/CSS/JS**  
  Simple and efficient front-end technologies to provide a seamless user experience.

- **Node.js (Backend)**  
  Fast and scalable backend using Express.js.

- **MySQL (Database)**  
  Store and manage your profile and project data with a robust database system.

- **LocalStorage**  
  To remember your preferences like dark mode, password protection, and music settings.

- **External Libraries**  
  - `jQuery` for interactive UI elements
  - `AOS` for scroll animations
  - `Chart.js` for dynamic project stats
